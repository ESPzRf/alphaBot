# Discord Moderation Bot

Стартовый модерационный бот: таймаут с готовым списком длительностей, кик и бан (+ бонусом `/unban` и `/remove_timeout`).

## ⚠️ Про Python 3.14

На момент сборки этого бота `discord.py` в своих официальных классификаторах заявляет поддержку
только до Python 3.12 (актуальная версия библиотеки — 2.7.1). Это не значит, что библиотека
не заработает на 3.13/3.14 — она почти целиком на чистом Python и для голосовых функций (которые
здесь не используются) полагается на отдельный пакет `audioop-lts`. Но официальной гарантии
совместимости с 3.14 пока нет.

Два варианта:
1. **Запустить как есть на 3.14** — скорее всего всё будет работать (бот ничего специфичного
   для голоса/аудио не делает), но если при установке/импорте вылезет ошибка — это из-за
   рассинхрона версий.
2. **Подстраховаться** и держать для бота окружение на Python 3.12, пока `discord.py` официально
   не подтвердит 3.14 — так безопаснее для продакшена.

## Установка

```bash
cd discord-mod-bot
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Впиши в `.env`:
- `DISCORD_TOKEN` — токен бота из [Discord Developer Portal](https://discord.com/developers/applications)
- `GUILD_ID` (необязательно) — ID твоего сервера, если указать — слэш-команды появятся
  на сервере мгновенно (без указания — обновление команд может занять до часа, это особенность Discord API)

## Настройка бота в Discord Developer Portal

1. Создай приложение → вкладка **Bot**.
2. Включи **Privileged Gateway Intents → Server Members Intent** (без него не будет работать кик/бан/таймаут).
3. Пригласи бота на сервер через OAuth2 URL Generator, scope `bot` + `applications.commands`,
   права минимум: `Kick Members`, `Ban Members`, `Moderate Members`.
4. Роль бота в списке ролей сервера должна быть **выше** ролей тех, кого планируется модерировать.

## Запуск

```bash
python bot.py
```

## Команды

| Команда | Права | Описание |
|---|---|---|
| `/timeout member duration reason` | Moderate Members | Таймаут по готовому списку: 60 сек, 5 мин, 10 мин, 1 час, 1 день, 1 неделя |
| `/remove_timeout member reason` | Moderate Members | Снять таймаут досрочно |
| `/kick member reason` | Kick Members | Кикнуть с сервера |
| `/ban member reason delete_message_days` | Ban Members | Забанить, с опцией удаления сообщений за 0-7 дней |
| `/unban user_id reason` | Ban Members | Разбанить по ID |

Бот сам проверяет:
- иерархию ролей (нельзя трогать того, кто выше или наравне с модератором/ботом);
- что нельзя применить действие к самому себе (и к другому боту — для таймаута);
- права бота на сервере (`BotMissingPermissions`, если не хватает прав).

Перед киком/баном бот пытается отправить пользователю личное сообщение с причиной
(если у него закрыты ЛС — просто пропускает этот шаг, ошибки не будет).
